# SaaS Pricing Plan Card

A modern subscription pricing card demonstrating inline text styling with `<span>` elements, custom Google Fonts integration, box model spacing, and interactive button transitions.

## 🎯 Objective
Combine Lessons 1 through 5 by integrating external web fonts and styling mixed typography within single text blocks while reinforcing box model layout and interactive CSS states.

## 🛠️ Tech Stack
* HTML5
* CSS3
* Google Fonts

## 💡 What I Learned (Lessons 1–5 Cumulative)
* **Lesson 1:** Structuring UI components with semantic headings, paragraphs, and action buttons.
* **Lesson 2:** Linking external CSS files and styling elements via class selectors.
* **Lesson 3:** Applying box model spacing (`padding`, `margin`, `border-radius`) and smooth `:hover` / `:active` transitions.
* **Lesson 4:** Controlling typography hierarchy using `font-size`, `font-weight`, `line-height`, and `text-align`.
* **Lesson 5:** Importing external fonts via Google Fonts and styling specific words or symbols inline using `<span>` tags and text decorations.

## 🚀 How to View
Open `index.html` directly in any web browser.
