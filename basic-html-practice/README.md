# Basic HTML Practice Page

This is my very first web development project built while following Lesson 1 of the SuperSimpleDev HTML & CSS course.

## 🎯 Objective
To understand the fundamentals of HTML structure, headings, paragraphs, and standard button elements without styling.

## 🛠️ Tech Stack
* HTML5

## 💡 What I Learned in Lesson 1
* How HTML uses start tags and end tags (`<tagname>content</tagname>`).
* Using `<h1>` and `<h2>` for page headings and structure.
* Displaying body text using the `<p>` paragraph tag.
* Adding basic interactive elements using the `<button>` tag.

## 🚀 How to View
Open `index.html` directly in any web browser.
