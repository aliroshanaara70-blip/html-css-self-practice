# Call-to-Action (CTA) Button Set

A collection of styled UI buttons created while learning CSS basics in Lesson 2 of the SuperSimpleDev HTML & CSS course.

## 🎯 Objective
Learn how to link external CSS stylesheets to HTML documents, target specific elements using CSS classes, and style text and buttons using background colors, borders, and typography properties.

## 🛠️ Tech Stack
* HTML5
* CSS3

## 💡 What I Learned in Lesson 2
* Linking external stylesheets using the `<link>` tag inside `<head>`.
* Selecting HTML elements using class attributes (`.class-name`).
* Customizing element background colors (`background-color`) and text colors (`color`).
* Applying font properties like `font-size` and `font-weight`.
* Styling button borders and changing cursor state using `cursor: pointer`.

## 🚀 How to View
Open `index.html` directly in any web browser.
