# Social Media Follow & Action Buttons

An interactive button component set demonstrating hover transitions, click animations, and box model spacing built in Lesson 3 of the SuperSimpleDev HTML & CSS course.

## 🎯 Objective
Master the CSS box model (padding and margins), customize dimensions, and implement interactive pseudo-classes (`:hover`, `:active`) with smooth CSS transitions.

## 🛠️ Tech Stack
* HTML5
* CSS3

## 💡 What I Learned in Lesson 3
* Using `padding` for internal component spacing and `margin` for outer element separation.
* Setting custom `border-radius` for rounded UI elements.
* Implementing interactive states using `:hover` and `:active` pseudo-classes.
* Applying smooth property transitions using the `transition` property.

## 🚀 How to View
Open `index.html` directly in any web browser.
