# Social Media Post Composer & Search Header

A clean UI widget set featuring a rounded search input bar and a social media status composer with a circular profile avatar, built while progressing through Lesson 7 of the SuperSimpleDev HTML & CSS course.

## 🎯 Objective
Combine proper HTML5 document structure, Google Fonts, inline text styling, and interactive button transitions with image cropping (`object-fit`) and custom-styled text input fields.

## 🛠️ Tech Stack
* HTML5
* CSS3
* Google Fonts

## 💡 What I Learned (Lessons 1–7 Cumulative)
* **Lessons 1–5:** Building clean HTML hierarchies, linking external CSS and Google Fonts, styling inline text with `<span>`, managing box model spacing, and crafting `:hover` / `:active` transitions.
* **Lesson 6:** Writing complete, standards-compliant HTML5 boilerplate (`<!DOCTYPE html>`, `<head>`, `<title>`, `<body>`).
* **Lesson 7:** Embedding images with `<img>`, preventing image distortion using `object-fit: cover` and `object-position`, creating circular avatars with `border-radius: 50%`, and styling `<input type="text">` elements and placeholders.

## 🚀 How to View
Open `index.html` directly in any web browser.
