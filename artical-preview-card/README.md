# Tech News Article Preview Card

An article preview card component focusing on advanced text formatting, font properties, line height adjustments, and interactive CTA buttons.

## 🎯 Objective
Combine Lessons 1 through 4 by applying fundamental HTML structure, box model spacing, hover transitions, and detailed CSS text styling (fonts, font weights, line height, font styles, and alignment).

## 🛠️ Tech Stack
* HTML5
* CSS3

## 💡 What I Learned (Lessons 1–4 Cumulative)
* **Lesson 1:** Building semantic document structures with headings, paragraphs, and standard button tags.
* **Lesson 2:** Linking CSS stylesheets, targeting custom class names, and applying background and text colors.
* **Lesson 3:** Managing inner spacing (`padding`), outer spacing (`margin`), and creating smooth hover (`:hover`) and click (`:active`) button transitions.
* **Lesson 4:** Formatting text using `font-family`, adjusting paragraph readability with `line-height`, applying `font-weight` variations, italicizing secondary text with `font-style`, and controlling text alignment.

## 🚀 How to View
Open `index.html` directly in any web browser.
