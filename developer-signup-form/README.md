# Developer Sign-Up & Quick Search Form

A dual-section UI layout featuring a centered brand search bar and a multi-row registration form, built to practice the CSS `display` property in Lesson 8 of the SuperSimpleDev HTML & CSS course.

## 🎯 Objective
Combine HTML5 structure, Google Fonts, inline typography, image sizing, and form inputs while mastering how `display: block` and `display: inline-block` control horizontal and vertical element flow.

## 🛠️ Tech Stack
* HTML5
* CSS3
* Google Fonts

## 💡 What I Learned (Lessons 1–8 Cumulative)
* **Lessons 1–7:** Structuring HTML5 documents, linking external fonts and stylesheets, styling inline text with `<span>`, applying box model spacing, creating `:hover` / `:active` transitions, sizing images with `object-fit`, and styling `<input>` fields.
* **Lesson 8:** Controlling layout flow using `display: block` (stacking elements vertically and centering with `margin: auto`) versus `display: inline-block` (aligning form fields side-by-side on the same row).

## 🚀 How to View
Open `index.html` directly in any web browser.
